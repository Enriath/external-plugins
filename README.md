## Resizing the overlay

Hold Alt (Option on macOS), hover over an edge until the resize cursor appears, then drag the edge or a corner. The item icons, quantity numbers, background, and optional free-slot label resize together. Hold Alt/Option and drag the body to move the overlay, or Alt/Option-right-click it to restore its default size and position.

Width and height resize independently, so asymmetric dragging stretches the visual. Distinct item groups keep their compact layout and are fitted into the saved rectangle; adding more groups shares the selected space among them.
